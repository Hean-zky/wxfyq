?常见问题

翻译一篇要多久？

一般 1–3 分钟。论文会切成小段一段段翻，页面上有实时进度，中途关掉浏览器才会中断。

我的 API Key 安全吗？

Key 只保存在你自己浏览器的 localStorage 里，直接发给你选的那家服务商，不经过任何中间服务器。不放心可以翻完去浏览器设置里清掉网站数据。

为什么提示「接口连不上」？

多半是那家接口不允许浏览器直接调用（CORS）。换 DeepSeek 或智谱基本都能用；也可以把 Base URL 改成自己的代理地址。

扫描版 PDF（图片）能翻吗？

不能。这个页面只提取 PDF 里的文字层，需要原文是可选中文字的电子版。扫描件请先用 OCR 工具转一遍。

生成的文件是什么？

一个单独的 HTML 文件，双击就能打开，不用联网。里面有「隐藏英文」按钮，还有每一段的💡大白话解释。
